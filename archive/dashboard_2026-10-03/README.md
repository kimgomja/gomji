# 산업재해 현황 대시보드

Streamlit으로 사고 기록의 발생 추이와 업종·지역·사고유형·재해정도별 분포를 살펴보는 대시보드입니다. CSV 파일을 업로드하지 않으면 **가상 샘플 데이터**가 표시됩니다.

## 화면 구성

- **현황:** 배너, 핵심 지표의 월별 미니 그래프, 업종·유형·지역 인포그래픽, 재해정도 구성과 상세 차트
- **사고 기록:** 필터 결과의 날짜·업종·지역·사고유형·재해정도 검색, 표 확인, 현재 검색 결과 CSV 다운로드
- **데이터 안내:** 파일 전체의 범위와 형식 검사 결과, 집계 기준과 해석 시 주의사항
- **근거 챗봇:** 별도 페이지에서 현재 사고 CSV의 지역 기록과 월별 그래프를 조회하고, `C:\SANUP-P`의 SIF 사고사례·사고조사보고서·KOSHA GUIDE를 검색해 인용 번호와 원문 링크를 확인

왼쪽 작업 메뉴에서 화면을 전환합니다. 상단의 재해정도 선택은 현황과 사고 기록에 함께 적용됩니다. 왼쪽 **조회 조건**에서 기간·업종·지역을 설정하고, **필터 초기화**로 전체 기록을 다시 볼 수 있습니다. 데이터 안내는 업로드한 파일 전체를 설명합니다.

## 실행하기

PowerShell에서 프로젝트 폴더를 연 뒤 실행하세요.

```powershell
uv run streamlit run src/shining_chatbot/app.py
```

브라우저에서 표시된 로컬 주소(기본값 `http://localhost:8501`)를 여세요.

챗봇 페이지의 **지역·월별 질문**은 현황 페이지와 같은 사고 CSV를 사용합니다. CSV를 업로드하지 않으면 가상 샘플 데이터로 답하며, 샘플에는 제주 지역 기록이 없습니다. 지역 기록이 없다는 답변은 실제 지역 사고가 0건이라는 뜻이 아닙니다.

안전 사례·지침 질문은 로컬 `C:\SANUP-P` 프로젝트의 완성된 검색 색인과 `src/retriever.py`, `src/rag_chain.py`를 그 프로젝트의 `.venv`에서 실행합니다. 다른 위치에 있다면 `SANUP_P_ROOT` 환경 변수로 경로를 지정하세요. 의미 검색과 답변 생성에는 `SANUP-P`의 `.env`에 `OPENAI_API_KEY`가 필요합니다. 키가 없으면 문자 검색으로 근거 문서만 표시합니다. 색인·원본 자료·키를 이 저장소로 복사하지 않습니다.

또는 활성화된 가상환경에서 실행할 수 있습니다.

```powershell
streamlit run src/shining_chatbot/app.py
```

## CSV 형식

UTF-8 또는 CP949 인코딩 CSV를 업로드할 수 있습니다. 필수 열은 다음과 같습니다.

| 발생일 | 업종 | 지역 | 사고유형 | 재해정도 | 재해자수 | 휴업일수 |
| --- | --- | --- | --- | --- | ---: | ---: |
| 2026-09-15 | 제조업 | 경기 | 끼임 | 중상 | 1 | 45 |

`재해정도`는 `경상`, `중상`, `사망` 중 하나입니다. `재해자수`는 1 이상의 정수, `휴업일수`는 0 이상의 정수로 입력하세요. 화면에서 샘플 CSV를 내려받아 형식을 확인할 수 있습니다.

사고 건수는 기록 행 수, 재해자 수와 휴업일수는 각 열의 합계입니다. 사망자 수는 재해정도가 `사망`인 기록의 재해자수 합계입니다. 이 데이터에는 전체 근로자 수가 없어 재해율을 계산하지 않습니다.
