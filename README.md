# 샤이니 챗봇

Streamlit으로 만든 기본 채팅 페이지입니다. 현재 답변은 예시이며 AI 모델은 연결되지 않았습니다.

## 실행하기

PowerShell에서 프로젝트 폴더를 연 뒤 실행하세요.

```powershell
uv run streamlit run src/shining_chatbot/app.py
```

브라우저에서 표시된 로컬 주소(기본값 `http://localhost:8501`)를 여세요.

또는 활성화된 가상환경에서 실행할 수 있습니다.

```powershell
streamlit run src/shining_chatbot/app.py
```

## Streamlit Community Cloud 배포 정보

- 저장소: `kimgomja/gomji`
- 브랜치: `feature/dashboard-chatbot`
- 메인 파일 경로: `src/shining_chatbot/app.py`

Community Cloud에서 위 값을 입력하면 이 페이지를 배포할 수 있습니다.
